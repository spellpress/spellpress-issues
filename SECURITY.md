# Security policy

## Supported application

Only the current hosted application at [spellpress.app](https://spellpress.app/) is actively supported.

## Report a vulnerability privately

Do not report suspected security vulnerabilities in public Issues.

Use [GitHub private vulnerability reporting](https://github.com/spellpress/spellpress-issues/security/advisories/new) when possible. If that route is unavailable, email [security@spellpress.app](mailto:security@spellpress.app).

A useful report includes:

- The impact of the issue
- The affected behavior
- Clear reproduction steps
- Relevant screenshots, recordings, or other evidence

Avoid accessing, changing, or deleting another person's information while investigating. Include only the evidence needed to explain the issue.

Ordinary bugs, card-data problems, and feature requests belong in the [public Issue Forms](https://github.com/spellpress/spellpress-issues/issues/new/choose).
